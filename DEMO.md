# Демонстрация на 90 секунд

Перед выступлением: `docker compose up -d`, открыть http://localhost:3000, нажать «Сбросить», оставить 1000 авто и дождаться «Модель готова к эксперименту». Локальная схема работает без внешней подложки. Проверить, что приложение открыто в масштабе браузера 100%. Полная демонстрация новых функций — в [DEMO-EXTENDED.md](DEMO-EXTENDED.md).

**0–15 секунд.** «Это Первая Речка. Дороги настоящие, из OpenStreetMap. Пользователь выбирает количество автомобилей; сейчас их тысяча, распределённая по 12 направлениям».

**15–30 секунд.** Нажать «Демо-сценарий». «Что произойдёт, если перекрыть этот участок Хабаровской улицы в обоих направлениях? Убираем из графа именно эти два направленных ребра и пересчитываем пути».

**30–45 секунд.** Переключить «До изменения» и «После изменения». «Шесть маршрутов поменялись. Все поездки остаются доступны. Бело-голубая линия показывает выбранный объезд, красный пунктир — закрытый участок».

**45–60 секунд.** Показать сравнительную панель и назвать разницу времени, процентов и длины с экрана. «Эти показатели считаются по одинаковым доступным поездкам. Количество авто и вклад домов влияют на нагрузку и время».

**60–75 секунд.** Нажать строку в «Куда переместился поток» и назвать прирост с экрана. «Вот соседний участок, который получил дополнительный поток. Одно локальное решение изменило нагрузку за пределами места перекрытия».

**75–90 секунд.** Нажать «Объяснить результат». «Объяснение построено по сохранённому расчёту и доступно без внешнего ИИ. Следующий эксперимент — оставить дорогу открытой, но уменьшить её пропускную способность. Это демонстрация механизма, не прогноз реальных пробок».

Цифры относятся к включённому набору `pervaya-rechka-v1`, количеству 1000 авто и исходным остальным настройкам. При другом спросе или составе сценария называйте значения с экрана. Запросы старого API без количества продолжают использовать 38 авто.
