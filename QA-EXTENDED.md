# Проверка расширенной версии

Исторический отчёт до пользовательских исправлений. Текущая модель домов, каталог парковок и поведение при отсутствии места описаны в [QA-FIXES.md](QA-FIXES.md).

13 ноября 2026 года. Приложение работает локально в Docker: http://localhost:3000.

## Изменения

По умолчанию в интерфейсе 1000 условных автомобилей; доступны число, ползунок и готовые значения от 1 до 10 000. Добавлены составные сценарии, точки А/Б/«Через», парковки, погода, существующий жилой дом и новые дома пользователя. Расчёт сохраняет совместимость с исходными запросами на 38 автомобилей и прежними записями MongoDB.

## Проверенные сценарии

В Chrome через интерфейс проверены:

- Выбор 1500 автомобилей: исходная карта и запрос используют именно 1500.
- Постановка А, Б и промежуточной точки на карте.
- Совместный сценарий: **1000 авто + дождь + ручная парковка 75% + удаление дома**. Спрос после — 999; обе личные поездки доступны; поиск места 60 → 180 секунд; коэффициент дождя 0,85.
- Переключение личной автомобильной и пешей геометрии «До / После» и объяснение сохранённого расчёта.
- Ручная парковка при 100%: «Мест нет», итоговое время `null`, выбранный ID не подменяется.
- Чистое изменение занятости одной парковки с 50% на 75% при остальных одинаковых условиях: итог **+120 секунд**.
- Автоматическая смена парковки при заполнении текущего варианта; выбранный вариант минимизирует сумму дороги, поиска и пешего времени.
- Новый дом на 40 жителей создаёт отдельную группу весом 2 авто; общий спрос 1000 → 1002.
- Снег применяется со скоростным коэффициентом 0,70.
- Сброс убирает маршрут, погоду, пользовательские занятости и изменения домов, возвращает 1000 авто.
- Телефон 390 × 844: личный маршрут с парковкой и снегом работает при блокировке всех внешних HTTPS-запросов. Горизонтального переполнения нет.

Регрессионный сценарий первоначального MVP также пройден: демо, исключение закрытых рёбер, прирост потока, переключение фаз, объяснение, автономная подложка, сброс, ручной выбор дороги, ошибка API и повтор, сужение, час пик, справка, мобильный размер, SVG без WebGL. В нём обновлены проверки формата запроса: пользовательский интерфейс теперь отправляет `scenario_type: composite`.

## Автоматические проверки

Полный запуск backend: **42 passed**. В браузере пройдены **23 проверки**: 13 регрессионных и 10 расширенных; оба отчёта содержат пустой список ошибок. `npm run typecheck` проходит, `npm run build` успешно выполнен при production-сборке Docker.

Проверки исходного движка и новых сценариев охватывают:

- Односторонность, параллельные рёбра, стабильные равные веса, неизменность базового графа.
- Два прохода назначения и время по финальным потокам.
- Запрет поворота в точке «Через» и поиск легального объезда через неё.
- BPR-примеры: 120 с свободного времени при `q/C=1` дают 138 с; в дождь — 162,35 с; уменьшение потока 5 → 4 при C=5 даёт 127,37 с.
- Поиск парковки 50% / 75% / 100%, максимум 900 с, недостижимую парковку, отсутствие парковок в радиусе, минимум общего времени и устойчивый ID при равенстве.
- Фоновый спрос дома, недопустимый отрицательный фон, добавление и удаление, пропуск нулевого веса, сравнение с исходными весами.
- Изменение количества авто с фиксированной опорной ёмкостью; личную поездку с нулевым вкладом в поток.
- Координаты, ссылки, диапазоны и отказ от сохранения некорректного запроса.
- Повторяемость составного сценария, сохранение параметров, привязок, геометрии и времён, чтение новым экземпляром API.

В действующей MongoDB сохранён составной расчёт с дождём, парковкой 75% и удалением дома. После пересоздания контейнера API результат прочитан без изменений, включая параметры, привязки, геометрию, разбивку спроса и времени. Сохранённый расчёт первоначальной версии на 38 автомобилей тоже читается и получает объяснение.

Итоговые JSON-отчёты и скриншоты находятся в `artifacts/browser-check.json`, `artifacts/extension-browser-check.json` и PNG-файлах рядом.

## Источники и границы модели

14 парковок имеют координаты OpenStreetMap; 2 демонстрационных точки у кольца отмечены в карточках. Въезд привязан к ближайшему допустимому узлу автомобильного графа; реальное положение въезда на местности не обследовано. Занятость везде сценарная. Жилой дом — OSM way 168693084, Хабаровская улица, 26; 20 жильцов и `k_auto=0,05` заданы условно. Маршрут пешком — прямая со скоростью 4,5 км/ч, не пешеходная навигация.

Ёмкости при пользовательском количестве фиксированы относительно опорных 1000 авто; они не измерены на местности. В запросах без количества сохраняется исходный масштаб 38 авто. Погода ручная, не прогноз. Условные и via-way ограничения поворотов не моделируются; сохранены направления и применимые via-node запреты из OSM. Внешний LLM не подключён: объяснение использует сохранённые цифры и возвращает `source: template`.

Проверен Chrome и эмуляция телефонного размера; Safari и физический телефон отдельно не проверялись. Публичное размещение не настроено.
