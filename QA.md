# Фактическая проверка MVP

Дата: 13 ноября 2026 года. Среда: Windows, Docker Desktop / Linux-контейнеры, Chrome. Основной стек запущен на http://localhost:3000.

## Сборка и сервисы

- Next.js успешно собран в production-режиме с TypeScript-проверкой внутри Docker.
- FastAPI и MongoDB запущены отдельными контейнерами; проверка готовности обоих сервисов проходит.
- `/api/health` возвращает `ready`, `mongodb: connected`, `pervaya-rechka-v1`, `is_test_network: false`.
- При остановке MongoDB `/api/health` и `/api/simulate` возвращают **503**. После запуска MongoDB готовность восстанавливается без перезапуска API.
- Два повторных seed-импорта в настоящую MongoDB оставили **1 набор, 1 сценарий**, число сохранённых расчётов не изменилось.
- Сохранённый запуск считан через `/api/runs/{run_id}` после пересоздания контейнера FastAPI; результат совпал полностью. `/api/analyze` использовал этот сохранённый запуск.

## Автоматические тесты

`python -m pytest backend/tests -q`: **21 passed**.

Проверены одностороннее движение, конкретное параллельное ребро, стабильный выбор при равных весах, два прохода назначения, расчёт итоговых времён, отсутствие пути, `null` при отсутствии сопоставимых поездок и нулевой базе, базовые веса сравнения, дробный спрос, частичное ограничение, запрещённый поворот, неизменность исходного графа и повторяемость. Также проверены seed, API-валидация, 404/422/503, понятное сообщение для недоступного действия, сохранение и чтение запуска новым экземпляром приложения.

API-тесты используют mongomock. Проверки настоящей MongoDB перечислены выше отдельно. В тестовой среде Starlette выдаёт одно предупреждение об устаревании интеграции TestClient с httpx; тесты проходят.

## Пользовательский сценарий в браузере

`node scripts/browser-check.mjs`: **13 проверок**, ошибок JavaScript не обнаружено. Проверки выполнялись через интерфейс установленного Chrome с отдельным временным профилем.

1. Загружаются базовое состояние, реальная дорожная сеть и подписи. Индикатор исчезает после отрисовки дорог.
2. Демо меняет маршруты, исключает закрытые рёбра и даёт положительный прирост потока.
3. «До / После» переключает состояние без перезагрузки страницы.
4. Объяснение строится из сохранённого результата без LLM.
5. Внешняя подложка включается и отключается; локальная схема остаётся работоспособной.
6. Сброс очищает сравнение и возвращает исходное состояние.
7. Нажатие на реальную дорогу показывает параметры и направление.
8. Ответ API 503 показывается как ошибка, после неё доступен повторный запуск. В этой браузерной проверке ответ 503 подставлялся тестом; реальное отключение базы проверено отдельно.
9. Сужение выбранной на карте дороги меняет пропускную способность, сохраняя доступность рёбер.
10. Час пик увеличивает веса тех же поездок в 1,4 раза.
11. Открывается и закрывается справка.
12. На экране **390 × 844** нет горизонтального переполнения; карта и демо работают при блокировке всех внешних HTTPS-запросов.
13. При принудительно отключённом WebGL доступны SVG-схема всех 963 рёбер, масштабирование и запуск демо.

Скриншоты визуально просмотрены: desktop, mobile, локальная карта и режим без WebGL. Они и JSON-отчёт находятся в `artifacts/` (папка исключена из Git).

На трёх лидирующих рёбрах Хабаровской улицы условный поток возрастает с 0 до 9 автомобилей. Это разные соседние рёбра, поэтому названия в таблице совпадают.

Цель до 2 секунд выполнена на этой машине; это измерение демонстрационного набора, не гарантия для произвольного графа.

Геометрия каждого маршрута проверена на связность, направление и отсутствие 149 импортированных запрещённых переходов. Ни один маршрут «После» не использует перекрытые рёбра. Повторный сценарий возвращает одинаковые маршруты и показатели.

## Расширения и ограничения

Реализованы анимация с паузой, наклон камеры, сужение, условный час пик и шаблонное объяснение. Внешний GPTunnel/LLM не подключён. SVG-режим показывает упрощённую дорожную схему без зданий, анимации и наклона.

Направления и манёвры проверены по данным OSM, не на местности. Импорт учитывает безусловные ограничения с одним `via-node`; условные и `via-way` ограничения не поддерживаются. Снимок содержит 624 отношения, из них 133 применимы к рёбрам включённого графа и дают 149 запрещённых переходов. Правильность не внесённых в OSM знаков не подтверждена. Спрос и пропускная способность условные; калибровки на реальном трафике нет. Пешеходы, общественный транспорт и управление светофорами в MVP не входят.

Проверен Chrome и эмуляция размера телефона; Safari и физический телефон отдельно не проверялись. Публичное размещение не настроено: Next.js, Python API и MongoDB работают локально в Docker.
