# Мобильный интерфейс: изменения и статус проверки

14 ноября 2026 года. База изменений — commit `424933a`. Основание: предоставленные владельцем `MOBILE-UX-AUDIT.md` и `MOBILE-UX-REDESIGN-PROMPT.md`.

**Полная браузерная приёмка не проводилась.** Изначально по указанию владельца тесты и сборка не запускались. Затем владелец отдельно разрешил пересобрать и перезапустить frontend без тестов: сборка прошла, новая версия запущена на `http://localhost:3000`. Выполнен отдельный просмотр геометрии окон в Chrome со свежими скриншотами, описанный ниже. Численные результаты и полная пользовательская матрица этим просмотром не проверяются.

## Что изменено

| Аудит | Изменение в коде |
| --- | --- |
| M01–M02 | Один мобильный breakpoint в CSS и `useAppEnvironment`: до 900 px или короткий экран до 1100 px. Панель, редакторы, справка, меню действий и настройки карты занимают всю ширину, включая landscape. Удалены правила узких правых карточек. Отступы и safe area находятся внутри окон. |
| M03, M05 | Дом и дорога редактируются в отдельных черновиках. «Готово» проверяет и применяет значения; отмена, крестик, Escape, фон, свайп заголовка и браузерный Back отменяют изменения и возвращают в исходный раздел. Новый объект до применения не входит в запрос расчёта. Перестановка дома сохраняет его черновик. |
| M04 | Смена разделов сохраняет незавершённую дорогу, точки и режим инструмента. Доступно продолжение через карту или меню действий. Начало другого инструмента приостанавливает дорогу; удаление черновика происходит явной отменой или сбросом. |
| M06 | На телефоне одна главная навигация: «Карта / Сценарий / Результат». Вкладки внутри панели показываются на desktop. Первый показ панели использует доступную высоту без скрытого автоматического раскрытия в QA-helper. |
| M07 | Мобильная карта начинает работу с кнопки «Действия». Отдельное окно объединяет маршрут, дом, дорогу и снос. Легенда, анимация, слои и второстепенные действия находятся в настройках карты. При постановке точек видны инструкция и действия текущего инструмента. |
| M08 | Установлены минимальные размеры зон кнопок 44×44 CSS px и основного действия 48 px; подписи tabbar — 12 px. Фактическая геометрия ещё требует измерений. |
| M09 | По умолчанию редактируется одна парковка с поиском и выбором. При наличии Б сортировка начинается с ближайших объектов. Полный каталог нескольких парковок доступен отдельной кнопкой и сохраняет виртуализацию. Есть пресеты 0/50/75/100%; пустой/неверный ввод не записывается в сценарий. |
| M10 | Карточки А / Через / Б получают подпись ближайшей улицы из имеющейся геометрии OSM. Координаты остаются дополнительными сведениями. Добавлена перестановка А и Б, сохранены порядок и удаление промежуточных точек. |
| M11 | У справки закреплённый заголовок с закрытием и одна прокручиваемая область. Редакторы используют такую же структуру с отдельными нижними действиями. |
| M12 | Ошибки соединения, длины и лимита точек остаются в инструменте до исправления. Проблемный конец выделяется на WebGL- и SVG-карте; линия сохраняется. |
| M13 | Нативные модальные `dialog` получают отдельные имена. Браузер исключает фон из взаимодействия и удерживает фокус; добавлены возврат фокуса и обработка Back. Прокрутка формы не закрывает редактор: свайп начинается только на заголовке. |
| M14 | Исправлен селектор «Снести дом …», обновлены helper выбора действия, сценарии мобильной анимации и проверки панели под новую структуру. Они подготовлены, но не запускались. |

Дополнительно: короткая стабильная подпись расчёта; пояснения к недоступному действию; резюме условий; переход к карте из результата района; сохранение позиций прокрутки разделов. На коротком landscape инструмент рисования уплотнён, чтобы оставить место для выбора точек. При клавиатуре учитывается visual viewport, фоновые tabbar и подвал скрываются. На мобильном подвале ссылки доступны горизонтальной прокруткой.

Математическая модель, backend, API-контракты, данные OSM, MongoDB и формат JSON-экспорта не менялись. Равенство численных результатов этой версии в runtime не проверялось.

## Что проверено

- Просмотр изменений исходников и проверка diff на пробельные ошибки.
- Статический ESLint для затронутых компонентов: без ошибок. Остаются предупреждения существующих императивных обёрток React/MapLibre, TanStack Virtual и неиспользуемых объявлений.
- По отдельному разрешению выполнен `npm run build`: сборка и встроенная проверка TypeScript завершились успешно. Перезапущен только локальный frontend; backend и MongoDB не останавливались.
- **Не запускались:** серверные и браузерные тестовые наборы, отдельная команда TypeScript-проверки. На внешний сервер эта версия не разворачивалась; реальное мобильное устройство не использовалось.

## Ширина в запущенной версии

Причина повторного появления боковых отступов: `localhost:3000` обслуживался прежним `next start`, в CSS которого оставалось `width:calc(100% - 16px)`. Новый файл `mobile-ux.css` в ответах той сборки отсутствовал. После обновления используется build `v8py1NfP4_C8z1GTA-ILl` и viewport с `viewport-fit=cover`.

В установленном Chrome с эмуляцией мобильного viewport прочитаны реальные `getBoundingClientRect()` открытых окон. Везде левая граница равна 0, правая совпадает с шириной viewport, горизонтальной прокрутки нет:

| Окно | Viewport | Измеренная ширина |
| --- | --- | --- |
| Сценарий | 320×568 | 320 px |
| Сценарий, как на скриншоте владельца | 400×725 | 400 px |
| Сценарий | 430×932 | 430 px |
| Сценарий, landscape | 844×390 | 844 px |
| Сценарий, планшет | 820×1180 | 820 px |
| Справка, действия, настройки карты, редакторы дома и дороги, cookie-баннер | 400×725 | 400 px у каждого окна |

Артефакты: `artifacts/mobile-width/inspection.json`, скриншоты `artifacts/mobile-width/*.png`. Ошибок JavaScript в этом просмотре не получено. Наборы `scripts/*check*` не запускались; сохранение расчётов, модель, остальные сценарии и реальная клавиатура этим просмотром не подтверждаются.

## Приёмка, оставленная на следующий разрешённый прогон

Обновлён `scripts/design-panel-check.mjs`: проверка первого открытия, полной ширины всех шести типов окон, landscape, неверного ввода с доступным закрытием, отмены существующего дома разными способами, возврата в список, сохранения рисуемой дороги между разделами и экземпляра карты. Скриншоты и геометрия будут записываться в `artifacts/mobile-ux/` только при фактическом запуске. Сам файл теста пока не проверен выполнением.

Размеры: 320×568, 360×640, 375×667, 390×844, 412×915, 430×932, 568×320, 667×375, 844×390, 768×1024, 820×1180, 1440×900. Предусмотрены тёмная тема и reduced motion.

Исходная пользовательская матрица не пройдена целиком. Ниже перечислены сценарии, которые ещё необходимо проверить полностью; просмотр ширины не заменяет их функциональную приёмку:

| Сценарии аудита | Следующая проверка |
| --- | --- |
| 1–2: запуск и навигация | Загрузка, ошибка/повтор, ширина окон, камера и прокрутка разделов. |
| 3: автомобили | Поле, слайдер, пресеты, границы, пустой ввод, ожидание и ошибка baseline. |
| 4–8: дорожные сценарии | Без изменения, перекрытие, запрещённый участок, сужение, час пик, демо, «До / После». |
| 9–10: личная поездка | А/Б, неполный маршрут, пять точек «Через», порядок, перестановка и перетаскивание. |
| 11–13: парковки | Все режимы, 0/50/75/100%, пустой поиск, выбранный объект, полный виртуальный каталог, заполненная/недоступная парковка. |
| 14: погода | Сухо, дождь, снег и комбинации с другими условиями. |

| 18: составной сценарий | Маршрут + парковка + погода + дом + существующая и новая дорога; сравнение прежних и новых запросов. |
| 19: результаты | Личный/районный результат, нет пути/сопоставимого времени, предупреждения, объяснение, карта и экспорт. |
| 20–21: справка, карта, восстановление | Длинная прокрутка, темы, слои, анимация, SVG без WebGL, ошибки/таймаут/повтор и сброс. |

Отдельно требуется реальное устройство: Safari/Android, экранная клавиатура, адресная строка, safe area, поворот при вводе, системные жесты Back, фокус и скринридер, увеличение текста. Для утверждения размера hitbox нужны фактические измерения; CSS-декларация сама по себе не является такой проверкой.
