# Расширение MVP

- [x] Локальные каталоги парковок и моделируемых домов, коэффициенты в конфигурации.
- [x] Составной сценарий: выбранное количество авто, погода, дорога и изменения спроса домов.
- [x] Личная поездка через точки с непрерывным учётом поворотов, парковка и разбивка времени.
- [x] Настройки и редактирование на карте; результаты, объяснение и экспорт.
- [x] Совместимость старого API и запусков; тесты формул, маршрутов и интерфейса.
